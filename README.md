# Wanderlust 🏡

### Airbnb-Inspired Property Listing Platform

Wanderlust is a full-stack web application inspired by Airbnb, built to explore and manage property listings. Users can create listings, upload property images, and share reviews through a responsive interface.

## 🌐 Live Demo

**[View Wanderlust Live](https://delta-project-ldad.onrender.com/listings)**

## ✨ Features

- **User Authentication:** User signup and login.
- **Authorization:** Restrict listing operations to authorized users.
- **Property Listings:** Create, view, edit, and delete listings.
- **Reviews:** Add reviews to property listings.
- **Image Uploads:** Upload and manage property images using Cloudinary.
- **Database Integration:** Store application data using MongoDB and Mongoose.
- **Interactive Maps:** Display property locations using Mapbox.
- **Responsive UI:** User-friendly interface for different screen sizes.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/anubhav6780/Wanderlust-Airbnb.git
```

### 2. Navigate to the project directory

```bash
cd Wanderlust-Airbnb
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory and configure the environment variables required by the application.

Check the project configuration files for the exact variable names and required values.

**Important:** Never upload your `.env` file, database credentials, or API secrets to GitHub.

### 5. Start the application

Check the `scripts` section in `package.json` to identify the correct start command. For example, if a `start` script is configured:

```bash
npm start
```

### 6. Open the application

Visit the local URL and port configured by your application.
